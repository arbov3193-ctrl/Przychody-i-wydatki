# Семейный бюджет — веб-приложение для iPhone

Репозиторий `arbov3193-ctrl/Przychody-i-wydatki` (перенесено из папки `budget/` репозитория Bolt Assistant).
Выкладывается на тот же Cloudflare, что и сервер Bolt Assistant.

## Адрес
`https://budget.boltassistant-b96f4c.workers.dev` — выкладывается сам при каждом push в `main`
(`.github/workflows/deploy.yml`). В Settings → Secrets and variables → Actions нужны секреты
`CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID` (те же, что в репозитории Bolt Assistant).
Установка на iPhone: Safari → «Поделиться» → «На экран Домой».

## Кто и зачем
Владелец (Артур) и жена, общий счёт в Erste Bank Polska (банк не присылает SMS). Оба iPhone.
Цель: записывать траты за месяц, распределять бюджет по категориям, суммы из банка сначала попадают
в «Разобрать», потом раскидываются по категориям.

## Устройство
- `src/worker.js` — Cloudflare Worker + Durable Object `House` (одна «семья» = один объект).
  Хранит: `key`, `name`, `members`, `categories`, `plan:YYYY-MM` {income, limits}, `tx:YYYY-MM` [траты],
  `inbox` [неразобранные], `rules` {магазин → категория}.
  API: `/api/create`, `/api/h/<id>/state|tx|tx/<txId>|categories|plan|member` (заголовок `X-Key`),
  `/api/in/<id>/<key>` — приём оплат из «Команд» iPhone (сумма вида «45,20 zł» разбирается).
- `public/` — само приложение (без сборки): `index.html`, `app.js`, `style.css`,
  `sw.js` (работает без интернета), `manifest.webmanifest`, иконки.
- Код семьи: `<id>.<key>` (10 + 16 символов); второй телефон подключается ссылкой `/?join=<код>`.

## Что уже сделано
- Создать бюджет / подключиться по коду или ссылке; у каждого телефона своё имя («кто тратил»).
- Экран «Месяц»: потрачено, осталось из бюджета, «≈ N zł в день до конца месяца», сравнение
  с прошлым месяцем, категории с лимитами и полосками (жёлтая > 85 %, красная — перерасход), «кто тратил».
- «Распределить бюджет»: доход месяца + лимиты по категориям, «свободно / распределено больше дохода»;
  следующий месяц берёт лимиты прошлого.
- ＋ трата: цифровая клавиатура, категории плитками, заметка, сегодня / вчера / дата, кто.
  Без категории — уходит в «Разобрать». Без интернета — очередь, отправка при появлении связи.
- «Разобрать»: оплаты из Apple Pay / скриншотов / ручные без категории; нажатие на категорию переносит
  трату в бюджет; магазин запоминается и в следующий раз подсвечивается первым.
- 📷 «Суммы со скриншота уведомлений»: распознавание на телефоне (tesseract.js 5.1.1 с jsdelivr, язык pol),
  находит суммы в PLN/zł и магазин, пропускает поступления (Wpływ…), отмечает уже добавленные раньше.
- Apple Pay автоматически: в «Ещё» пошаговая инструкция для «Команды» → «Автоматизация» → «Транзакция»
  → «Получить содержимое URL» (POST JSON: amount, merchant, who) на ссылку `/api/in/<id>/<key>`.
- «История» по дням, фильтр по категории, правка суммы / заметки / даты (перенос в другой месяц) / удаление.
- «Ещё»: имя телефона, участники, ссылка для жены, категории (эмодзи, название, добавить, удалить).
- Светлая и тёмная тема по настройке iPhone.

## Проверено
Локально через `wrangler dev`: создание, приём «45,20 zł» и «PLN 120.00», трата с категорией, план,
отказ при неверном ключе. Разбор текста уведомлений (Płatność kartą … PLN w …, Zapłacono … zł u …,
поступления пропускаются). На iPhone ещё не проверялось.
